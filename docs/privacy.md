# Keycadence Privacy Policy

Keycadence collects no data, and has no network access, so it cannot send anything off your Mac.

**Key presses.** Keycadence uses the macOS Input Monitoring permission to detect key presses. Each one only chooses a sound and where it plays in the stereo field. Key presses are never stored or logged. macOS does not deliver keystrokes typed into password fields.

**Keystroke totals.** If you turn on Count keystrokes, Keycadence saves how many keys you pressed each day, on your Mac. It never records which keys. This is off by default, and you can reset it at any time.

**Calendar.** If you turn on the calendar quiet rule, Keycadence checks whether an event is happening now. Event details are not stored.

**Bluetooth.** If you turn on the Bluetooth quiet rule, Keycadence checks whether a paired device is connected.

**Changes.** Any change to this policy will be published at this address.

Questions: [open an issue on GitHub](https://github.com/jdbrewer/keycadence/issues).
